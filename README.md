Grade Calculator

Name: Jennifer Barnedo  
Section: IT3R4

Description

The Grade Calculator is a simple web-based program that checks whether a student has passed or failed based on the grade entered by the user.

The program was created using HTML, CSS, and JavaScript. It allows the user to enter a grade and displays "Passed!" if the grade is 75 or higher. If the grade is below 75, it displays "Failed."

How to Run

1. Open the GitHub repository.
2. Download or clone the repository.
3. Open the `index.html` file in a web browser.
4. Enter a grade in the input box.
5. Click the Calculate button.
6. The program will display whether the student passed or failed.
